# 第二阶段：AI 素养与工具使用（12 次课）

版本：2026-09-15 研究方案，尚未试教。承接第一阶段编程基础，衔接第三阶段项目实战；以下课序、评价和分龄安排是教学设计建议，尚无学习成效数据。采用小班导师带领，开课人数与师生配置由总方案确定。

## 进入条件与分层

先让学生完成一次“点击计分、条件过关、重复生成、重开归零”的任务，解释变量与状态如何变化，并用“操作—预期—实际”描述一个错误。7–9 岁能实现并解释状态重置即可，函数封装按能力选做。能完成但解释困难者先补基础，不因年龄直接进入工具进阶；接口进阶须另行通过文本基础诊断，包括输入输出、变量、条件、循环、函数与基本调试。

| 能力路径 | 本阶段重点 | 任务深度与课堂时间 |
| --- | --- | --- |
| 7–9 岁 | 说清规则、检查结果、中文方法意识 | 图卡、口述、积木或本地模板；导师处理真实 AI 操作。建议每次 75 分钟，含 10 分钟休息，教学 65 分钟；12 次共 13 小时教学。Skill/MCP 只做等价认知，不要求配置 |
| 10–12 岁 | 写任务说明、小步修改、依据证据调试 | 可继续使用积木；经文本诊断后再用简短 JavaScript，结合任务卡及导师组织的真实 AI 协作。每次 90 分钟含 10 分钟休息，教学 80 分钟；12 次共 16 小时教学。账号资格未通过者由成人操作；可写方法卡，不要求真实 Agent 加载 |
| 13–18 岁 | 解释代码、验证来源、复用流程与理解连接 | 同为 16 小时教学；通过文本基础诊断且环境合格后选做兼容 Skill 和真实只读 MCP。年龄达标不等于文本基础或产品使用资格达标 |

低龄路径缩小功能数和术语深度，保留表达、操作、检查、复述；与较高龄路径的教学时数和技术覆盖不同。

## 稳定概念与少量工具

训练从数据中调整模型参数；推理使用已学到的参数与当前输入生成结果。补充上下文、保存对话或编写 Skill，不等于当场重新训练模型。多模态是处理文字、图像等不同形式的信息，图片理解结果也需要检查。[模型开发说明](https://openai.com/policies/how-chatgpt-and-our-foundation-models-are-developed/) 支持上述概念。

Agent 可用“模型＋指令＋工具”解释；回答“已完成”与实际执行成功是两种证据。[Cursor Agent 概述](https://cursor.com/docs/agent/overview) 用于核对组成，产品本身不作为未成年学生必备工具。提示词是任务指令，上下文是相关背景、代码、样例和资料；提供相关信息比堆叠修饰语更适合课堂练习。[OpenAI 提示工程指南](https://developers.openai.com/api/docs/guides/prompt-engineering)

Skill 以含元数据和指令的 `SKILL.md` 为核心，可附资源，兼容 Agent 按需使用；它记录做法。MCP 是连接应用与外部工具、数据的协议；它解决连接。二者可以组合，也可单独使用，均不是新的模型。[Agent Skills](https://agentskills.io/home)、[MCP 介绍](https://modelcontextprotocol.io/docs/2026-07-28/getting-started/intro)

| 工具位置 | 选用范围 | 账号与备课边界 |
| --- | --- | --- |
| 学生共同底座 | 浏览器＋离线图形/HTML 模板＋本地编辑器；文件副本保存版本，高龄可用本地 Git | 无供应商账号；教师课前备齐可运行模板、错误样例、预设 AI 输出、来源卡和版本副本。不承诺这些完整教学包当前已建好 |
| 国内真实 AI 首选核查对象 | CodeBuddy 中国版的代码问答/辅助修改，由成人先试跑 | 官方协议要求未满 18 岁由监护人陪同阅读，未满 14 岁还需儿童隐私声明与同意；同时要求实名认证账号。尚未核定儿童声明全文、实际所选终端条款、账号资格及机构教学适用范围，因此是待验收候选，不是全龄可直接开通的结论。[中国站协议](https://www.codebuddy.cn/agreement/)、[隐私声明](https://www.codebuddy.cn/privacy/) |
| 在线 AI，可选 | 一个经机构审核的对话工具；ChatGPT 仅作条件合格时的候选 | ChatGPT 至少 13 岁或所在地区更高最低年龄，未满 18 需家长/监护人同意；13 岁以下教育场景由成人实际操作。禁止把成人账号交给孩子轮用。[条款](https://openai.com/policies/row-terms-of-use/)、[课堂年龄说明](https://help.openai.com/en/articles/8313401-is-chatgpt-safe-for-all-ages) |
| 编程 Agent 演示，可选 | 成人导师使用 Cursor 展示计划、差异与工具返回 | Cursor 当前要求至少 18 岁或当地成年年龄，取更高；家长同意不覆盖此门槛。18 岁学员也须逐项核查。[Cursor 条款第 2 节](https://cursor.com/terms-of-service) |
| 协议进阶，待建设 | 经审查的本地客户端＋只读教学 MCP 服务＋虚构作品数据；兼容 Agent 为另一个可选环节 | 真实环境须在开课前建设、测试；不接学校系统、个人云盘、生产库。手动客户端真实调用 MCP 不等于模型自主调用，也不等于已完成 Agent 集成 |

账号资格、当地可用性、机构条款、数据设置须分别核对。查阅日 ChatGPT 支持列表未列中国大陆，国内课程不以其登录为前提；备选产品若年龄许可未经确认，也不开放学生账号实操。[支持地区](https://help.openai.com/en/articles/7947663-chatgpt-supported-countries)

第二候选 TRAE：已核对的企业版隐私政策提出未成年人须有监护人同意；个人版用户协议正文此次未成功取得，不能把企业版描述推定为个人版儿童许可，地区适用范围和机构教学成员资格仍待确认。[企业版条款](https://docs.trae.cn/enterprise_terms-of-service-for-trae-enterprise)、[企业版隐私政策](https://docs.trae.cn/enterprise_privacy-policy-for-trae-enterprise)。开课只选一个通过验收的真实 AI 工具，不要求学生遍历候选产品。

**真实 Vibe Coding 实操班开课门槛**：确定允许目标学生使用或允许成人带领教学的真实 AI 环境；完成适用条款、账号与数据处理核查；成人在实际教室设备上试跑“需求→生成计划→修改→测试→恢复”，检查并发、额度和延迟并留记录。低龄由成人现场交互，孩子负责提需求、预测、验证；无学生账号资格者不能记为独立操作 AI。若在线候选均不满足，可评估机构管理的本地模型路线，但须另做许可证、硬件、响应质量与课堂管理评估并建设，当前未配备。门槛未通过不得按真实实操班开课。

无账号预审材料只作概念练习和课堂故障降级：学生写提示、比较预设回答、修改本地作品并验证，之后补齐缺失的真实交互。不能用材料练习宣称完成真实 AI 协作或 MCP 调用。作业标记“真实 AI 交互／教师演示／预设输出练习／协议模拟／真实协议调用”，不混记能力。

## 逐课安排

编号 B01–B12，对应总课程第 13–24 次。除特别标明，操作按上述分龄深度实施；不要求低龄学生掌握英文术语。

| 课次与主题 | 理论抓手 | 操作任务 | 产物 | 检查方式 |
| --- | --- | --- | --- | --- |
| B01 AI 怎样生成 | 训练与推理、生成的不确定性 | 先用图卡整理例子中的规律，再比较同题两份回答；明确图卡只是类比 | “能帮什么／怎样检查”卡 | 学生区分学规律与使用规律，指出一处需验证内容 |
| B02 把请求说清 | 目标、背景、范围、约束、验收 | 将“做个好玩的游戏”改成明确规则；逐次补背景，比较输出 | 两版任务说明与差异记录 | 同伴只读说明即可说出输入与预期结果 |
| B03 检索与来源 | 生成、检索、证据的区别 | 为作品介绍核对一条事实，打开教师选定来源并找支持句；资料不足则写未知 | 含标题、链接、查阅日的来源卡 | 找得到支持内容；识别“有链接但不支持结论” |
| B04 草图与多模态 | 不同输入、识别与推断 | 用自己的无个人信息草图描述按钮、状态、动作；纠正一处误读 | 草图与行为说明 | 用点击路径验证功能，不能仅凭相似外观过关 |
| B05 认识 Agent | 模型、工具、返回、停止条件 | 给“查作品数量”排步骤，分辨模型回答、工具结果和失败；遇无权限选择停止 | 流程图与日志标注 | 指出能证明执行的返回；不把文字承诺当执行 |
| B06 Vibe Coding：计划 | 需求→计划→小改 | 为计分游戏只新增重开；选择必要背景，将任务拆成两步 | 任务卡、两步计划、基线版本 | 每步只有一个可检查目标，能解释相关变量与状态；文本进阶再解释函数 |
| B07 Vibe Coding：验证 | 正常、重复与边界测试 | 按计划改动，检查差异；点击、连续点击、重开后再点击 | 可运行版本、测试表 | 先预测再运行；解释自己接受或拒绝的一处改动 |
| B08 调试与恢复 | 复现、定位、单一假设、版本 | 处理“点一次加两分”，写错误报告；修复后恢复上一版本再验证 | 复现记录、差异、恢复证据 | 相同步骤可复现；说明为什么修复与恢复成功 |
| B09 Skill：复用方法 | 适用条件、步骤、例外、复查 | 为计分检查写中文方法卡；已具备文本基础者整理为 `SKILL.md`，用于第二个作品 | 方法卡/文件及一次修订 | 找出第二个作品的不同规则；纯文件不冒称已被 Agent 加载 |
| B10 MCP：连接与权限 | 请求、返回、读取、修改 | 模拟读取虚构作品清单，拒绝删除；合格进阶组观察真实本地只读调用 | 连接图、权限表、带模式标记的日志 | 说清数据来自哪里；区分模拟、真实连接与模型调用 |
| B11 新工具与失效 | 同题比较、迁移、替代路径 | 同一需求和测试清单比较两种做法；注入断网、额度不足或接口变化 | 比较表与备用操作卡 | 比较结果、耗时、帮助次数和失败；无证据不排名 |
| B12 使用能力闯关 | 表达、协作、验证、无 AI 迁移 | 演示作品并解释关键规则，现场关闭 AI 完成未练过的同层级微修改并验证；提交任务、测试与版本记录 | 微作品、个人关卡记录、过程包 | 可运行、关键规则解释、适龄无 AI 新情境微修改三关必过；其余必需证据按下文核验，未过补修换题复测 |

## 两份可备课教案

### B07：让计分与重开可靠运行

课前材料：验收通过的真实 AI 环境、可离线打开的初始游戏、三列测试表、可恢复副本；另备正确/错误两份预设候选修改用于故障降级。尚未通过环境核查时只能先教方法练习，不能认定为真实实操完成。

90 分钟流程：0–10 回顾任务并预测结果；10–22 讲解状态与验收；22–40 结对完成一个小修改；40–50 离屏休息；50–73 运行正常和连续点击测试；73–85 交换作品复测、解释差异、保存版本；85–90 写退出条。导师先追问“你预计是什么”，再让学生看结果；不直接代写修复。

验收样例：初始 0，点击 3 次为 3，重开为 0，再点击为 1；一次点击不得重复计分。检查积木或代码中的计分变量与重置步骤，文本进阶再检查函数封装，并说明一处 AI 建议为何被接受。发生错误时只修改与假设相关的一处，再复测。

7–9 岁使用 75 分钟：10 分钟回顾、10 分钟演示、15 分钟单功能操作、10 分钟休息、15 分钟测试、10 分钟口述、5 分钟退出条；可只完成重开与再计分两个检查，高龄另查快速连续点击。退出条回答“我改了什么，什么证据让我相信它能用”。

### B10：方法可以复用，权限需要边界

沿用 B09 的计分检查方法；材料为两份虚构作品记录、请求/返回卡、允许读取与不允许修改卡。90 分钟：0–10 复用方法；10–22 画应用—客户端—服务—数据关系；22–40 发读取请求并核对返回；40–50 休息；50–73 注入“删除作品”和夹在数据中的“忽略规则”文本；73–85 处理撤销权限/空结果并复查；85–90 解释 Skill 与 MCP 的分工。

低龄按上一教案的 75 分钟节奏做角色卡，只判断“读了什么、能否修改、由谁确认”。通过文本基础诊断者才进入接口操作；真实扩展还须通过环境验收：固定教学目录、虚构数据、仅列出与读取、无写入工具、服务端范围校验、调用日志、关闭服务后读取失败。只读标注不是权限实现；返回的数据也不是新的操作指令。[MCP 工具规范](https://modelcontextprotocol.io/specification/2025-11-25/server/tools)

真实调用可由学生在本地客户端手动发起，记录请求、返回和失败证据；如再连兼容 Agent，另行核对账号并观察其实际调用。未具备环境时改用协议模拟，不能把完成模拟记为掌握真实连接；不以删真实文件演示权限。

## 评价、备课与更新

B12 与总方案保持同一进阶门槛，三关均须通过：①按说明启动并完成约定核心功能；②本人解释关键规则，预测新输入并指认状态变化；③现场关闭 AI，用积木或已学文本完成未提前展示答案的同层级微修改并验证。迁移可变更门槛、增加一个分支或调整计分；允许自己的规则卡及语法表、适龄读题与操作支持，不允许导师或同伴给出解法。支持类型单独记录，不以打字速度代替理解。

此外，任务表达须包含目标、范围与验收；验证恢复须保留正常/边界测试及一次恢复后复查；来源与权限须能追溯一条依据，正确标记真实/模拟并判断读取与修改。三关和这三项证据全部通过才认定本阶段概念与本地编程部分达标。逐项使用总方案的“独立完成／经提示完成／共同完成／仍需练习”；给过解法的关键关卡须换题独立复测。未过者先补修缺项、换情境复测，再决定进入第三阶段，不以成品或总分跳过关卡。

真实 AI 使用与真实 MCP 调用另立记录，保存实际环境、任务、调用/返回、学生与成人操作分工及验证结果。只有预设材料、演示或协议模拟者，可完成相应概念与本地代码部分，但不能宣传已达成真实 AI 使用、独立操作或真实 MCP 调用；缺少的真实环节补做并验收后再标记。工具名记忆和生成速度不计为掌握。

每期开课前核查官方年龄、地区、条款和功能，试跑同一基准任务，并验证无账号备课包；每次课前检查登录、额度、网络和恢复文件。教师只使用虚构或经处理的资料，不把姓名、联系方式、面部照片和密钥放入提示。服务失效时立即切换材料，记录失效原因与本次未覆盖的真实操作，下次补教。

每期结束汇总学生卡点与需提示位置；月度核对可变工具层，稳定保留表达—计划—小改—测试—版本主线。更新记录写明日期、官方来源、变化、受影响课次和替代任务；新增工具须先用既有验收清单试跑，再决定是否纳入。当前网站预览的预设回答和模拟 MCP 可辅助讲解，不等同于已建成真实 AI 教学平台。
