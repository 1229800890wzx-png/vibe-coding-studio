# 教育官网与后台选型调研

> 历史初筛，已被用户新增的“高 Star、不限教育、完整业务复用”要求更新。当前结论与源码证据见 [FULLSTACK_SHORTLIST.md](FULLSTACK_SHORTLIST.md)。下文 Strapi 首选等建议不再生效，保留作早期背景。

核验日期：2026-09-13。范围：官网、咨询预约和后续教育业务的技术选型；尚未部署候选后台，以下为官方文档与源码许可的案头比较。

## 结论

当前用户明确方向是新东方式教育机构官网，视觉参考滴滴的橙色，前端按自身课程和品牌定制。第一阶段暂按“课程展示 → 了解教学与师资 → 咨询 / 预约”规划，在线支付、录播、直播、考试还不是已确认需求。

在这个范围内，优先考虑 **Strapi 社区版作为内容后台，独立定制 React 前端**。若首期就要做班级、排课、课时、学员与顾问跟进，并希望沿用 Java 技术栈，则考虑 **RuoYi-Vue 后端 + 独立官网前端**。若依是开发底座，教育模块需要开发，不是安装后就具备教务功能。

只有确定要售课和在线学习时，再把 MeEdu / EduSoho 提升为主选。无需为了官网先部署整套网校。

## 候选比较

| 候选 | 官方已提供的能力 | 我们仍需实现或核验 | 当前匹配度 |
| --- | --- | --- | --- |
| Strapi | 内容模型、运营编辑后台、媒体库、REST API；可独立搭配前端 | 课程、导师、作品、FAQ 等模型；预约写入接口、校验、防滥用与私有读取；教务非内置 | 官网与内容运营优先 |
| RuoYi-Vue | Spring Boot、权限、角色、日志、代码生成、多端 Token 接入 | 官网内容发布、课程、预约、学员、班级与课时等业务模块 | Java 与定制业务优先 |
| MeEdu | PHP / Laravel，前后端分离，点播、购课、学员登录、学习统计、PC / H5 | 商用许可；现有 React 官网对接；支付、短信、视频服务配置；直播与考试等商业版本边界 | 在线售课优先 |
| EduSoho | 网校教学、招生与管理；课程 API 文档 | 商业授权、页脚品牌约束、各版本 / 插件实际交付范围，以及自定义前端所需 API 覆盖 | 较完整网校需求再评估 |

- RuoYi-Vue 为 MIT；需保留相应许可与版权声明。[官方许可](https://github.com/yangzongzhuan/RuoYi-Vue/blob/master/LICENSE)

- 2026-09-13 查询 GitHub 元数据，四仓库均未归档；最近推送分别为 Strapi 09-12、RuoYi-Vue 08-26、MeEdu 06-17、EduSoho 02-20。推送时间只能表明仓库活动，不能代替版本稳定性和部署验证。

本次未确认商业产品报价。自托管也需要服务器、域名与存储；选用短信、视频点播、直播等服务时再核算对应费用。

## 前端定制方向

[新东方官网](https://www.xdf.cn/beijing/)可借鉴的是课程分类、找课路径、师资与咨询入口，不照搬其全部业务线。建议官网导航为：首页、课程体系、教学方法、导师团队、学员作品、关于我们。城市 / 校区切换只在真实存在多个校区时加入。

首页信息顺序建议：品牌与课程入口 → 按学习阶段 / 兴趣找课 → 课程体系 → 教学过程与作品 → 真实师资 → 常见问题 → 咨询预约。适龄范围、校区、师资与成果需要真实资料后填入。

配色参考[滴滴官网](https://www.didiglobal.com/)的橙色品牌方向。建议以白色与浅暖灰为底，橙色用于主按钮、选中态和少量强调，正文用深灰。具体色号属于后续设计提案，尚未抽取或认定滴滴官方品牌色。按钮文字对比度需要实测，不能仅把所有蓝色批量替换为亮橙色。

现有网站的交互作品可保留为教学成果说明。新定位应先调整信息层级，再判断是否保留大幅平板主视觉。当前蓝白设计的历史约束见 IMPLEMENTATION.md；用户本次的橙色与教育官网方向是后续改版的新依据。

## 建议落地顺序与验收

1. 启动现有源码供用户查看，确认课程展示与作品演示的保留范围。
2. 制作橙色教育官网首页与课程详情样稿，验收桌面 / 手机信息层级、阅读、找课和咨询入口。
3. 用选定后台实现一条最小真实链路：运营创建课程并发布 → 官网读取 → 用户提交预约 → 仅授权管理员可查看和更新跟进状态。成功提示必须以服务端已接收为准。
4. 将课程、导师、作品、FAQ 和首页配置迁出硬编码；预约联系方式不能通过公共内容 API 暴露。浏览器不存管理员令牌。
5. 根据真实业务再增补学员、班级、课时或在线学习；不提前启动多套后台。

如需搜索引擎收录课程详情，正式上线时评估预渲染或服务端渲染；本地预览仍保留现有 Vite 项目，选型不要求立即重写。
