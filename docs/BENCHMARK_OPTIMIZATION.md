# 少儿课程发现与报名连续性优化

本轮将新东方官方公开页面中的课程分类、班期条件和服务入口作为参考，修复 VIBE CODING 自身的选课与报名问题。对照依据是[官方来源调研](research/NEW_ORIENTAL_2026-09-14.md)，不是已经核实的新东方原生微信小程序全流程。

当前本地公开目录中的 **29 门课程均为 TEST / 验收资料**。截图里的价格、老师、课表和孩子用于验证真实本地服务，不是正式售卖承诺、真实师资宣传或实际学员成果。一对一仍为预约申请：老师及期望时段需要后续确认，不能当作已锁定课表或正式报价。

## 从原状到已实现行为

下表“我方原状”来自本地代码与浏览器复现；“已实现”来自本轮源码及验证。它们不被写成新东方产品事实。

| 决策或流程 | 我方原状 | 本轮已实现 | 对照依据 |
| --- | --- | --- | --- |
| 从首页找到服务 | 体验、正式班和高级一对一的选择关系不够直接。 | 首页并列三条服务路径；常规课程按内容和上课条件筛选，一对一继续独立选老师。 | 官方课程方向与服务入口支持这种组织方式；三路径划分属于本项目设计。 |
| 列表价格进入详情 | TEST 课程 28 在正式班列表显示 ¥99，详情未带入条件，混入免费体验并显示 ¥0。 | 白名单参数传递 kind / mode / campusId / startFrom / startTo；详情用同条件筛选真实班期，起价和班期数量一起变化。正式班 62 保持 ¥99，体验班 63 只有显式放宽后才显示。 | 天津课程卡将时间、形式与费用并列；具体一致性修复针对我方已复现缺陷。 |
| 理解课程是否适合 | 详情已有目标与大纲，但缺少速览与快捷定位；缺大纲时曾显示默认 8 次。 | 展示适龄、实际大纲课次数、当前匹配班期数，以及学习收获 / 课程大纲 / 班期费用锚点；未发布数据明确待公布。 | 官方介绍以学习方向和路径解释课程；不照抄内容。 |
| 对比班期 | 体验与正式班混排；多班期 CTA 曾滚到页面说明。 | 正式 / 体验分组，显示真实老师、北京时间、课表数量、地点、名额和每位孩子的班期总价；多班期 CTA 定位实际班期区，单个可报班期可直接进入。 | 官方公开页面支持按上课条件选择；锚点与分组细节是我方设计。 |
| 放宽条件与返回 | 详情未明确继承列表上下文；空结果时缺少逐项解释与恢复路径。 | 已选条件可逐项移除；真实零结果保留关键词。详情明确“查看本课程全部班期”，只放宽本页，返回列表保留搜索和筛选。 | 本项目交互要求；未对竞品未获取的错误状态作判断。 |
| 登录后继续报名 | 登录与原选择缺少稳定续接；登录后孩子信息读取失败可能混同登录失败。 | 安全 returnTo 保留目标班期并支持登录页刷新；原会员登录成功后，孩子 GET 失败可恢复，不重新要求登录、不自动提交交易。 | 历史帮助体现账号与学员信息分别核对；当前恢复逻辑由我方需求决定。 |
| 确认孩子与报名条件 | 孩子归属主要靠页尾说明，返回页面没有统一重查，旧勾选可能继续沿用。 | 班期页前置当前孩子；onShow 重查费用、库存和规则，刷新期间禁止提交。费用、规则、课表或孩子变化撤销勾选并给出页内原因；满班、已开课、资料不全有明确说明。 | 我方既定多孩子、名额与权益边界，不声称复刻了竞品内部逻辑。 |

未新增账号、订单、支付或预约基础系统。登录继续使用原会员身份，课程和班期继续使用教育 API；收费报名调用原 CartApi，免费体验沿用原预约接口；一对一沿用原 CRM 申请及权限。此次浏览器验收没有调用报名、短信、下单或付款接口。

## 验证范围与后续边界

[组合验收脚本](../tooling/bootstrap/verify-benchmark-ux.playwright.js) 使用实际公开目录和原会员密码登录，本机报告为 `.runtime/benchmark-ux-report.json`。最终 **8 组全部通过**，结束于 2026-09-14 07:59:21（Asia/Shanghai），无页面异常。覆盖筛选白名单和北京时间边界、首页分流与价格一致、班期放宽与返回、真实零结果恢复、登录续接、真实孩子切换撤销协议勾选、一对一游客选师后的原账号登录续接及 320 / 390 / 430 / 1440px 指定路由布局。脚本只在原登录成功后的孩子 GET 上主动中断一次；后续读取仍由真实服务处理，没有伪造成功响应。

费用 / 规则变化的前端撤勾逻辑、旧慢响应隔离、失败清旧价、满班原因另经限定内存场景验证；它们不替代浏览器流程或后端并发检查。两页 Vue 模板、脚本和样式编译检查通过；本轮 H5 与 mp-weixin 完整构建均以 exit 0 结束，构建原始日志及交付副本由统一验收导出记录。没有修改服务器或管理后台代码。

上述证据不代表微信原生小程序的真机、手机号授权、审核、真实商户支付、退款或性能验收已完成。正式开放售课仍需发布真实课程、师资、校区、价格、服务条款及主体配置。新东方原生逐页调研的待验证范围继续保留在[研究报告](research/NEW_ORIENTAL_2026-09-14.md)。
