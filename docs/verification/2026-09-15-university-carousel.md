# 导师页院校轮播验收

此为第一版阶段性记录。用户后续要求持续滚动，现已替换为单向无缝循环；最新验收见 `2026-09-15-university-continuous-scroll.md`。

地址：`http://127.0.0.1:4188/mentors#mentor-background`。2026-09-15，桌面 Edge Chromium 与移动视口。

## 交付

- 原院校文字表格替换为 13 所大学的本地官方校徽/标志轮播；包含上海交通大学、LSE、剑桥大学。
- 使用“世界顶尖名校”统一介绍，中英文校名、国家和学校官网链接齐全；保留原有配色、行业经历、学习价值与教学情境。
- 首尾往返自动浏览，单次间隔 5.2 秒；左右按钮、原生触控/触控板横向滚动、Home / End 与方向键。
- 图片失败时保留学校名称并显示字母回退。校徽来源见 `docs/design/university-sources-*.md`。
- 静态服务补充 JPEG 的正确 MIME 类型。
