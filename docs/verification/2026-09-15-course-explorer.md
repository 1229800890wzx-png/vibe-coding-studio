# 课程预览与 AI 新知接入验证

日期：2026-09-15。运行入口：`http://127.0.0.1:4188/courses`。

## 实现范围

- 保留暖白橙品牌配色，使用精细双层边框、内侧高光与轻阴影。
- 首页、课程列表与详情复用 `CourseExplorer`，课程选择依赖后台公开列表。
- 创意启蒙 3 个、AI 项目创作 5 个、作品成长计划 3 个知识点，包含说明、目标和本地互动。
- 支持大模型、上下文、Agent、多模态、Vibe Coding、Skill、MCP、调试和版本等内容；大模型回答和 MCP 连接明确为教学示例。
- 讲解与练习页签切换时保留练习状态，课程/知识点切换则重新开始对应练习。
- 移动端点击课程卡定位到预览，快捷入口正确转移焦点；未知课程只显示自己的后台说明。
