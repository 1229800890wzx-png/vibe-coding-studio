## 实测结果

1. `mvn.cmd ... -pl yudao-server -am package -DskipTests` 构建成功；1157 个 Java 源文件的新鲜度检查通过。首次编译在 `EduAdmissionService` 使用 Java 21 `List.getFirst()` 处失败，改为已判空后的 `get(0)`，Java 17 重编译通过。首次重试还遇到内存不足，限制 Maven/服务堆内存并串行浏览器验收后成功。
2. `verify-education-flow.mjs`：18 项真实 API 检查通过，覆盖家长归属隔离、课程发布、体验预约去重与库存、学习资格、私有文件、作业提交、教师反馈、成长报告、作品授权及撤回。
3. `verify-education-trade.mjs`：10 项检查通过，覆盖同 SKU 多孩子、真实报价/订单、名额并发、取消、部分退款、退款上限和调班。使用本地 **mock 支付**，未执行真实支付或真实退款。
4. 真实 Chrome：官网表单必填校验、邮箱咨询提交、成功回执；管理端查询同一条 CRM 记录并保存内部备注；API 再读确认备注持久化。
5. 真实家长登录 API 建立会话后，H5 显示已预约课、下一次课、教师反馈和成长报告。未测试真实短信注册。
6. 390px 浏览器下家长中心、成长报告和官网课程展示可用；家长中心和官网课程无水平溢出。截图在 `output/playwright/`，不提交图片或私有登录态。
7. 最终 4 项 API 核对通过：浏览器备注持久化、演示儿童更新、3 张官网卡片关联已发布的 12 课时课程、官网网关拒绝管理接口（404）。
