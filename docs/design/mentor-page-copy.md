# 导师页面内容与结构

2026-09-15 最新方向：高水准、精品化的导师团队是品牌的核心优势，导师页应鲜明传达团队的学术积累、科研经历与前沿技术视野，并介绍具体导师。用户明确要求移除教学手记、课堂交互示例、教学理念三个模块。

## 首屏文案

- 中文标题：第一行“我们的核心优势：”，第二行“高水准导师团队。”
- 英文短句：Exceptional minds. Real experience.
- 团队简介：世界顶尖名校的学术积累，顶尖 AI 科技大厂的科研一线经验。让孩子向持续接触前沿技术的导师学习。
- 背景标签：世界名校背景 / 大厂科研经历 / 前沿技术视野。
- 主要入口：“认识我们的导师”，指向个人资料区。

宣传重点落在团队背景与经验本身；不添加未提供或未核实的奖项、学历、人数与成绩数据。

## 当前页面

1. 紧凑的团队介绍：左侧以“我们的核心优势：高水准导师团队。”建立宣传重点，右侧呈现世界名校与一线 AI 科研背景简介、三个背景标签及“认识我们的导师”入口。
2. 团队背景：左侧“世界顶尖名校，多元的学习视野。”，右侧“顶尖 AI 科技大厂的科研经历。”，说明导师在科研岗位接触前沿 AI 技术，了解研究进展与行业发展。
3. 13 所学校的官方校徽连续滚动，保持既有配色、暂停与手动浏览功能。
4. 个人导师介绍：照片、姓名、教育背景、科研经历、研究方向。2026-09-16 已按团队提供的信息加入乔明君（科大讯飞人工智能研究院资深研究员）、薛煌（利兹大学人工智能硕士、一线科技大厂研发人员）。未提供的照片、研究方向等字段留空，不推断个人学历或任职背景。
5. 通用咨询入口与页脚。

## 个人资料填充

数据文件：`src/mentor-profiles.js`，当前 `mentorProfiles = []`。收到真实资料后填入条目：`id`、`name`、`photo`、`education`、`researchExperience`、`researchFocus`。除 `photo` 为图片路径外，其余展示字段为文字。图片优先放在 `public/mentors/` 并使用对应本地路径；当前不请求不存在的照片。

只要有实际资料，页面就展示真实条目，空白预留位置与整体待补充说明自动消失。个人背景不能由团队校徽名单推断；不把学校或企业写成机构合作关系，不附加未核实的 QS 名次、个人职位级别或荣誉。
