# AI 新知与工具使用：课程内容方案

状态：已于 2026-09-15 接入运行网站的首页、课程列表和课程详情。三门课程的说明与大纲已同步到既有统一后台的本地隔离环境（48081）。本页说明教学内容与网站预览，不代表已开设班期。

## 页面定位

主文案：**从编程基础出发，理解 AI，学会用新工具创造。**

三条学习路径继续保留。新增内容按前置能力进入课程，而不把 Skill、MCP 当作与启蒙课平行的招生阶段。页面仍使用暖白与橙色、精细双层边框；课程内容通过选择卡、知识点导航和练习预览逐层展开。

## 课程模块

| 模块 | 对孩子提出的问题 | 学习内容 | 动手练习 | 所属路径 |
| --- | --- | --- | --- | --- |
| 编程基础 | 程序怎样按照规则行动？ | 顺序、条件、循环、变量、函数、输入与输出；比较预期和实际结果 | 为小游戏增加计分和重开，解释为什么分数发生变化 | 创意启蒙，延伸至项目创作 |
| AI 与大模型 | AI 为什么能回答，也会出错？ | 模型、训练与使用的基本区别；提示词、上下文；区分生成内容与经过验证的信息 | 比较同一任务在缺少背景和补充背景时的回答，并检查一个错误 | 创意启蒙中的体验，项目创作中的系统理解 |
| 多模态与 Agent | AI 怎样理解画面，又怎样使用工具？ | 文字、图片等不同输入；模型与具有工具和指令的 Agent 的区别；一次工具调用如何返回结果 | 从简单界面草图说明按钮行为，并观察工具调用是否完成任务 | AI 项目创作 |
| 高效 Vibe Coding | 怎样让 AI 按自己的想法一步步完成作品？ | 写清目标、范围、上下文、约束和验收条件；先计划、再小步修改；检查关键代码、运行结果、报错和改动 | 只增加“计分与重开”，验证点击加一、重开归零，避免同时改动无关页面 | AI 项目创作 |
| Skill：可复用的方法包 | 怎样把有效的方法保存下来，再用一次？ | 以 SKILL.md 记录用途和步骤，可附参考资料、模板或脚本；在兼容工具中按需使用；理解复用后仍需验证 | 编写“小游戏检查”Skill，用它检查两个作品，再补充遗漏的检查步骤 | 完成基本 AI 协作练习后的项目创作；进阶复用 |
| MCP：连接工具与数据 | AI 怎样从外部拿到需要的信息？ | AI 应用、MCP 服务、工具与数据之间的连接；请求与返回；读取与修改的不同权限 | 在教学环境读取模拟作品清单，辨认“读列表”和“删除作品”的差别 | 已理解输入输出和工具调用的项目创作；进阶连接 |
| 调试、验证与版本管理 | AI 改错了，怎样找到问题并恢复？ | 看懂关键代码；复现报错、检查差异、设计正常及边界情况；区分临时检查点与长期版本记录 | 找出重复计分问题，保存修复版本，再演练恢复上一版本 | AI 项目创作贯穿，作品成长计划强化 |
| 新技术观察与迁移 | 换一个新工具，还能用学过的方法吗？ | 用真实任务比较工具能力、限制和操作方式；认识更新后的 Agent、技能和连接能力；选择适合任务的方式 | 用相同任务说明和验收清单比较两种工具，说明差异与选择理由 | 作品成长计划 |

## 三条路径在网站上的表达

- **创意启蒙**：从表达想法、理解程序规则开始，初步认识 AI 能做什么、哪些结果需要检查。
- **AI 项目创作**：理解 AI 与工具，练习 Vibe Coding 协作；具备基础后再接触 Skill、MCP，完成能运行、能解释的项目。
- **作品成长计划**：持续调试与迭代，复用技能、连接合适的数据工具、记录版本，形成自己的作品与方法。

Skill 与 MCP 既可分别使用，也可能在一个工作流中结合。Skill主要记录“如何完成任务”的知识和流程；MCP规定应用与外部工具、数据等交互的连接协议，不能把二者混成同一种插件。

## 课程预览的交互设计

点击上方“AI 项目创作”，下方展示五组知识点：“AI 与大模型”“高效 Vibe Coding”“Skill 技能包”“MCP 工具连接”“调试与版本”。多模态与 Agent 放入首组的展开内容。

每个知识点使用同一结构：**这是什么 → 动手试试 → 学习目标**，练习内直接显示检查结果。基础概念首先用中文解释，英文术语作为辅助标签。

- Vibe Coding：比较模糊需求和包含目标、范围、验收条件的任务说明；点击步骤查看每一步需要提供什么信息。
- Skill：预览简短的方法包，选择不同作品后点击“按方法检查”，比较同一方法发现的不同问题；不把安装技能等同于训练模型。
- MCP：在讲解中认识应用与服务的连接关系，操作本地模拟连接、读取作品、撤销权限与尝试修改，观察返回内容与授权范围。
- 调试与版本：比较修改前后结果，切换测试条件并预览恢复版本。

练习已用本地 React 状态实现，明确标注“互动示例”；MCP 和 AI 回答分别标注模拟连接与预设回答，不调用外部模型或真实 MCP 服务。练习不产生学员完成记录。咨询仍走统一后台，并且仅在收到真实回执后显示成功。

## 已实现的页面入口

- 首页按阶段和关键词筛选已发布课程，支持 Skill、MCP、Vibe Coding 等新模块关键词。
- `/courses` 默认展示 AI 项目创作的 Vibe Coding 预览；三条路径共有 11 个知识点，包含讲解、目标和互动。
- `/courses/:id` 复用同一预览并展开后台课程大纲。未知课程只显示自身后台内容，已下架或未知地址不展示其他课程的练习。
- 点击 Skill/MCP 快捷入口后焦点进入对应内容；手机点击课程卡会跳至课程预览；在讲解与练习之间切换保留练习状态。
- 课程描述、大纲和发布状态继续由统一后台管理。互动教学正文位于 `src/course-lessons.js`，练习位于 `src/lesson-exercises.jsx`，当前随网站代码发布。

## 课程表述与更新原则

固定主线是程序基础、表达问题、协作、验证与迭代。变化较快的产品界面和新特性放入可更新的主题单元，按备课时官方资料确认。不承诺掌握某个工具即可领先、独立开发所有产品或保证产出。

当前未确认招生年龄、每节课时长、班型和讲师配置，因此本方案不填这些信息。课程进阶按实际前置能力判断；工具实操使用适合教学的账号与模拟资料，并遵循工具的实际使用条件。
