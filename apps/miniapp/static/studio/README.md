# Website assets in the miniapp

The 2026-09-16 editorial snapshot is adapted from the current official website's `src/course-lessons.js`, `src/showcase-content.js` and `src/university-backgrounds.js` in the `codex/website-glass-type` design worktree. The original images are under `public/art/showcase`. Images here are resized JPEG versions for mobile delivery, not new student works.

University marks under `pages/studio/static/universities` are raster versions of the website's existing marks. Source URLs are retained in `edu/website-snapshot.json`. They indicate team members' education backgrounds, not institutional partnerships. Individual teacher details come from the existing public teacher API.

`art.woff2` is the Latin subset of Cormorant Garamond already used on the official website; the accompanying OFL is in `FONT-LICENSE.txt`. Chinese text uses native system fonts. The line icons were drawn for this miniapp.
